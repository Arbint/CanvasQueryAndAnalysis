# Student List

The student list is the column that shows the list of students that's comming out from the AggregationNodeGraph, double click on any node in the node graph will trigger this list to show the list of student that node is outputting.

On the top, the student list has the following helpers:

    * a filter to allow filtering on active and inactive students
    * sorting by first name, last name, and SSID.
    * a download button to download the list of student as .csv
    * a copy student emails button that will copy all student emails seperated by a ,

The student list will list out students with the following infomation:

    * First Name
    * Last Name
    * SSID
    * login id
    * Email(composed with login id@student.uiwtx.edu)
