# Comment Box

* The comment box is the same comment box in Unreal Engine bluerpint. it is used in the Aggregation graph to help group a node tree into the comment box, and leave a note as the title of the comment box.

* The comment box can be created through the existing node create menu triggered by the tab button.

* The comment box has color settings.

* The commnet box has a label part that the user can double click to change the text

* the user can drag the comment box to move every node in the comment box

* When a node is dragged away from the comment box, it is no longer part of it.
