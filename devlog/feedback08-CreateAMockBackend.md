Create a Mock Backend

For demostration purposes, create a mock backend server that can be launched by a new script called launchMock.bat

this mock backend server behaves like the real backend, providing the same api endpoints, but with mock data in a simple database locally.

The origional backend and front end should not be changed
The launchMock.bat will just simple launch the mock backend instead, the front end will not see a difference.

This mock data should be able to be pushed to github.
