We want to have another tab in the center area called student course audit.

On the top, the user should be able to put in:

* The student ID
* Start Semester
* End Semester
* A check box to use course list.

The user then is able to press an Audit button. 

Once the Audit button is pressed, the system should search and display the list of courses the student has taken.

The semester range of the course should be: If the check box to use course list is on, then use the courses already listed in the course list, Otherwise, use the semester range set in the Start Semester to the End Semester, inclusive on both start and end.

The list of courses should be a table that has each course being a row, and the following columns:

* name 
* code 
* instructor
* term 
* grade 

Make each column able to be sorted just like what course list is able to do.
